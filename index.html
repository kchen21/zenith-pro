Saving & Loading Data Guide

1. Saving / Exporting Data

Tap the Export (download) button in the top header. This downloads a complete backup file containing all custom asanas, modifiers, calisthenics drills and stretches.

2. Loading / Importing Data

Tap the Import (upload) button in the top header. Choose any previously exported Zenith .json file to restore your full custom library and progress instantly.

3. Cross-Device Portability

Because Zenith PRO runs locally in your browser, exporting JSON backups allows you to transfer your full routine library and progress across desktop, tablet, or phone effortlessly.
